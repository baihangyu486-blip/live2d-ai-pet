# Live2D 模型使用说明

项目作者：FuFu

Live2D 为可选形象。首次使用可以直接配置 AI 服务并开始聊天，之后再导入喜欢的模型。

## 导入

1. 准备好完整模型目录，包含 `.model3.json`、`.moc3`、纹理及清单引用的表情、动作等资源。
2. 打开「角色 → 导入模型」，选择 `.model3.json` 文件。当前入口不直接导入压缩包。
3. 导入器检查清单与关联资源，将所需文件复制到应用数据目录，保留资源的相对目录结构。
4. 导入成功后可在角色页预览；已导入列表可以切换其他模型。

当前支持 Version 3 模型清单。清单须包含 Moc 和至少一张纹理；资源路径应位于模型目录内，缺失资源、越界路径和超过 512 MB 的导入会被拒绝。模型清单本身上限为 2 MB。与清单位于同一目录的额外 `.exp3.json` 文件也会一并保留。

模型兼容性取决于实际资源和 Live2D 运行时。界面只呈现当前模型可用的表情、姿势及动作；不同模型拥有的操作可以不同。

## 切换与停用

「不使用 Live2D」会清空当前模型选择并关闭其展示，已导入文件仍然保留。再次选择列表中的模型即可启用。

形象不会决定角色姓名或人设。名称、身份、性格、称呼和回复习惯在「设置 → 角色」单独管理；导入、切换或停用不会清空聊天、记忆、日记和好感。

## 保存与公开范围

导入副本保存在 Electron `userData` 下的 `models/imported/`，原始模型文件不会被移动或删除。旧工作副本中已有的本地模型仍保留在磁盘；文件不存在时显示重新导入提示，不自动使用其他角色替代。

仓库根目录的 `models/` 已列入 `.gitignore`，并通过 `package.json` 的 `build.files` 从应用打包范围排除。公开源码与安装包不需要附带角色模型。`.gitignore` 不会追溯删除此前已经进入 Git 历史的文件；发行前应核对实际提交与产物内容。

模型素材的使用、展示和再分发遵循其自身授权。项目作者署名与第三方模型、运行时许可证是不同事项；应保留已有第三方版权和许可声明。
