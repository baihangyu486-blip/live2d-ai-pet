# AI 伴侣 · 产品与界面说明

项目作者：FuFu  
更新日期：2026-09-10  
适用项目：`live2d-ai-pet`

本文记录当前界面的结构与实现边界，替代早期以固定角色和房间仪表盘为中心的方案。文件名保留以维持已有链接；软件版本仍为 1.3.0。

## 产品方向

以聊天为起点，保存值得记住的小事，让用户自己决定角色的名字、性格与形象。少女感通过樱花粉、爱心、圆润气泡和少量闪光装饰表达，主要操作仍保持清楚。

产品显示名是「AI 伴侣 · AI Companion」。角色名称读取配置，Live2D 是可选的表现层；换模型不等于换人设，无模型不等于功能缺失。

## 一级入口

| 页面 | 内容与布局 | 实现边界 |
| --- | --- | --- |
| **陪伴** | 完整聊天占据主区域；旁边是可收起的心情、关系和相伴状态，以及一句日记预览、暂停主动陪伴。 | 使用现有聊天界面与逻辑，不另写一套简化聊天。图片理解、语音能力仍依赖已配置服务。 |
| **回忆** | 「记忆」和「日记与时光」页内切换。记忆支持全部/置顶筛选与置顶；日记、片段和里程碑按时间呈现。 | 只展示已有保存数据。没有记录时显示空状态，不用示例填充真实用户页面。 |
| **角色** | 左侧可选 Live2D 预览；右侧导入、停用、已导入列表和人设编辑入口。 | 预览按需加载。导入模型不替换名称、人设、聊天和记忆。 |
| **设置** | 独立分组窗口，每次呈现一个主题，底部保留全局保存。 | 完整保留现有配置控件与业务接口，不以删功能换简洁。 |

没有保留独立「心情」「房间」「时光」一级页。心情归入陪伴状态，时光归入回忆；取消缺少独立操作价值的房间装饰和首页重复摘要。

## 聊天功能保留范围

- 会话切换、新建、清空与管理。
- 图片附件、确认后发送的识屏附件、贴纸与语音输入。
- AI 等待状态、停止生成、失败重试。
- 消息引用、复制、收藏、撤回、语音文字和图片预览。
- 收藏筛选、表情库、贴纸导入与编辑。
- 历史检索及 JSON、Markdown、完整备份导出。

聊天页负责消息与输入，设置负责连接和策略。主界面中的聊天使用现有 `chat.html`，避免出现功能分叉。

## 七组设置

最终按现有控件与保存关系落为七组，优先确保功能可找、绑定保持完整。

| 分组 | 保留内容 |
| --- | --- |
| 连接 | AI 地址、密钥、模型列表、手动 ID、刷新、测试、保存。 |
| 角色 | 人设方案、上一版还原、另存方案、角色档案、生成预设及高级参数；模型导入、切换、停用、大小、适用的表情/外观/姿势/动作。 |
| 陪伴 | 回复模式、主动强度、问候和 AI 主动聊天、间隔、暂停、活动与屏幕感知；好感、相伴打卡、纪念日及提醒。 |
| 记忆 | 自动记忆、固定与清空、世界书条目和常驻规则。 |
| 聊天 | 会话、历史检索与导出、显示细节、贴纸开关、频率、冷却和规则编辑。 |
| 声音 | TTS 引擎、音色、参考音频、情感、音量与语速；STT 地址、密钥、模型和语言。 |
| 应用 | 自启动、语音缓存、退出与项目信息。 |

设置分类支持键盘方向键、Home/End 和焦点反馈；切换分类保留各自滚动位置。小窗口使用顶部分类条，大窗口使用侧栏。原有 130 个控件与容器 ID 保留；新增全局保存按钮避免跨分类查找保存入口。

## 视觉规范

| 用途 | 色值 | 使用方式 |
| --- | --- | --- |
| 奶白底色 | `#fff8fc` | 主背景和留白。 |
| 浅樱花粉 | `#ffe4ef` | 轻强调区域、爱心占位、选中区域附近。 |
| 莓粉 | `#dd4e8a` | 发送、保存等主要按钮与选中态。 |
| 深梅色 | `#57334d` | 主要文字和标题。 |

界面使用本地中文无衬线字体。爱心是稳定的识别元素；闪光和小装饰集中在空状态和角色页，消息区域避免装饰干扰。统一圆角、分隔线、按钮高度与输入框间距，去掉编号式注释说明、密集玻璃层和重复大标题。

页面切换使用短暂淡入；减少动态效果时停用不必要动画。角色预览只在角色页需要时加载，隐藏或离开该页时停止持续渲染；关闭 Live2D 后释放预览实例。

## 模型与角色边界

模型导入器检查 Version 3 清单与其引用资源，复制必要文件到应用 `userData/models/imported/`；停用只取消当前选择。模型缺失或渲染失败有明确反馈，聊天保持可用。

可用操作来自实际模型清单及已有表达资源。原来针对某个模型的发型和姿势按钮，只有对应资源存在时才出现。普通导入模型仍可使用其声明的表情与动作。

本地 `models/` 已分别从 Git 跟踪候选与 builder 打包范围排除，文件继续保留在磁盘。详细规则见[模型使用说明](model-import.md)。

## 实现结构

```text
主界面 home.html
  ├─ 陪伴：完整 chat.html
  ├─ 回忆：Home 数据快照
  └─ 角色：Home 数据快照 + 按需 Live2D 预览
设置 panel.html
  └─ 分类导航 + 已有配置表单
          │ preload / IPC
          ▼
主进程：聊天、主动行为、语音、记忆、日记、心情、关系、模型导入与存储
```

没有为了展示而新建一个声称已经完成的 AI 引擎。人格取自已有角色配置；主动陪伴、感知、记忆和情绪使用已有模块。天气、换装、实时通话、任意桌面操作和新的多维人格系统未列入当前能力。

## 验收边界

公开截图使用隔离示例数据。浏览器预览与模拟 IPC 检查用于验证页面、状态和接口边界；实际 Electron 启动、Windows 窗口行为、真实服务及新安装程序另行验收，不互相替代。

后续重点是：无模型完整使用、不同模型不破坏排版、原有聊天功能可达、全部设置可保存、关闭与重启保持记录，以及干净环境安装与打包。具体项目见[发布检查清单](release-checklist.md)。
