# 可选 Live2D 运行库

项目作者：FuFu

没有 Live2D 模型时，聊天、回忆、角色设置和已配置的语音可独立使用。此源码预览不再分发 Live2D Cubism Core。

需要显示模型时，请从 [Live2D 官方 SDK 下载页](https://www.live2d.com/en/sdk/download/web/) 获取 Cubism SDK for Web，按官方条款使用，将其中的 Core/live2dcubismcore.min.js 复制到本项目 vendor/live2dcubismcore.min.js，再导入自己的模型。该本地运行库已加入 Git 忽略规则。

官方仓库也将 Core 单独管理，见 [CubismWebSamples](https://github.com/Live2D/CubismWebSamples#live2d-cubism-core-for-web)。该运行库的许可与本项目源代码许可不同。
